# Security Certs

Study notes for two IT security certifications.

## Exams

- [**CompTIA Network+ (N10-009)**](comptia-network+/README.md) — 28 sessions
  - `note/chapter/` — session summaries
  - `question-bank/` — placeholder
- [**ISC CISSP**](isc-cissp/README.md) — 34 sessions
  - `note/chapter/` — session summaries
  - `note/chapter/intermediate/` — per-session Mermaid diagrams + 6 SVG overviews
  - `question-bank/` — 12 MCQ sets + 16 archived result CSVs

## Conventions

- Chapter files: `session-{NN}-video-{NNN}-to-{NNN}_{description}.md`
- Intermediate files: lowercase kebab-case
- Directories: singular nouns (`note/`, `chapter/`, `tip/`, `intermediate/`)
- Mermaid diagrams render natively in this Docsify site
