## Usage Notes

- Each MCQ set opens in a **new browser tab** as a standalone HTML application — it does not use the Docsify site chrome.
- Questions are shuffled on each load. Select an answer, then click **Submit** to see the explanation.
- Your score is tracked in the progress bar at the top of each set.
- Archived results from prior practice sessions are available in the `result/` subdirectory as CSV files.
